# Plan: Add RNNoise Background Noise Suppression

## High-Level Goal

Background noise (traffic, keyboard, etc.) triggers false VAD detections, causing the agent to think the user is speaking. Add pipecat's built-in `RNNoiseFilter` to suppress background noise on incoming audio for both WebRTC and Twilio transports.

## Important Technical Notes

### RNNoiseFilter is a transport-level filter, not a pipeline processor

`RNNoiseFilter` extends `BaseAudioFilter` and is passed via `TransportParams(audio_in_filter=...)`. Pipecat applies it inside the input transport (`BaseInputTransport._audio_task_handler`) before frames enter the pipeline. It is NOT inserted into the `Pipeline([...])` processor list.

The custom `TwilioInputTransport` extends `BaseInputTransport`, so it inherits the filter application automatically via the same code path.

### Twilio resampling chain

Twilio phone audio goes through: 8kHz mulaw -> 16kHz PCM16 (in `mulaw_to_pcm16`) -> 48kHz (RNNoise) -> 16kHz PCM16. This is three resampling steps. The user has explicitly opted to apply RNNoise to both transports. If phone audio quality degrades noticeably, we can revisit and skip RNNoise for Twilio.

### Resampling at 16kHz

RNNoise operates internally at 48kHz. When the transport sample rate is 16kHz (both WebRTC and Twilio in this project), pipecat's RNNoiseFilter automatically resamples up to 48kHz, applies noise suppression, and resamples back down. The default resampler quality `"QQ"` (Quick) is fine for low latency.

### Silent fallback if pyrnnoise not installed

If `pyrnnoise` is not installed, `RNNoiseFilter` silently degrades to a passthrough (no error, just a log message). During verification, look for the positive confirmation log line `"RNNoise filter enabling resampling: 16000 <-> 48000"` -- its absence means the filter is NOT active.

### Deployment: native dependency

`pyrnnoise` depends on the `librnnoise` C library. Verify that `pip install pipecat-ai[rnnoise]` succeeds in the deployment environment (Docker). If it fails, the Dockerfile may need a system package (e.g. `apt-get install librnnoise-dev` or similar).
